## 2. 改造决策（已确认）

| 决策点 | 结论 |
|---|---|
| 管理端鉴权 | **用户名密码登录**（PBKDF2 加盐哈希存储），Cookie 会话；`accessToken` **仅保留给 `/sub` 订阅鉴权** |
| 本期范围 | **仅产出方案文档**，不改代码 |
| 部署形态 | **后端托管 Vue 构建产物**（同源、单端口、无 CORS） |
| 业务服务层 | `Services/` 三层**原样保留复用**，不重写 |
| `/sub` 端点 | 原样保留，**不并入登录体系**；`content-type` 保持现状 |
| 鉴权粒度 | **仅保护 `/api/*`**（白名单除外）；SPA 壳与前端路由公开，登录跳转由 Vue Router 守卫完成（详见卷 03） |
| CSRF 防护 | Cookie `SameSite=Lax` + 写操作要求自定义头 `X-Requested-With: fetch`（详见卷 03） |
| 空凭据语义 | 管理端登录 **fail-closed**：未配置用户名/密码一律拒绝；空 `accessToken` 放行仅适用于 `/sub` |
| 会话有效性 | Cookie 会话与凭据摘要（用户名\|密码哈希）绑定，**改密/改名后旧会话自动失效** |
| 登录加固 | 固定时间比较防时序侧信道；同来源连续失败 5 次锁定 30 秒；失败文案统一防用户名枚举 |
| 实施单元 | 阶段 1+2 **同一分支连续实施、合并为同一发布单元**（禁止无鉴权中间态上线） |

## 3. 阶段与步骤总表

阶段之间**必须可独立回退验证**；每一步都有明确「验收」与「验证命令」。

| 阶段 | 名称 | 步骤 | 产出 |
|---|---|---|---|
| **0** | 现状盘点与基线锁定 | 0.1 环境/构建基线 · 0.2 API 缺口清单 · 0.3 接口契约(DTO) | 契约文档、缺口清单 |
| **1** | 后端 REST API 化 | 1.1~1.8（见卷 02） | JSON API 全量、旧 handler 下线 |
| **2** | 管理端鉴权 | 2.1 认证中间件/端点 · 2.2 前端登录接入 · 2.3 鉴权测试 | 登录会话、受保护 API |
| **3** | 静态托管与 SPA 回退 | 3.1 托管配置 · 3.2 回退路由与 `/sub` 优先级 | 单端口同源托管 |
| **4** | Vue3 前端工程 | 4.1 脚手架 · 4.2 路由/状态 · 4.3 api 模块 · 4.4 布局壳 | 可运行前端骨架 |
| **5** | 页面逐项迁移 | 5.1 登录 · 5.2 仪表盘 · 5.3 规则管理 · 5.4 导入 · 5.5 配置 · 5.6 设置 | 全页面 SPA |

> **实施单元约束（v2）**：阶段 1（API 化）与阶段 2（鉴权）必须在同一分支连续完成、作为同一发布单元上线——阶段 1 单独上线会让全部管理 API（规则增删改、设置改写）处于无鉴权公开状态。

## 4. 红线约束（前后端分离后**必须继续成立**）

来自项目既有可靠性的硬约束，改造中不被破坏：

| # | 约束 | 承载方 |
|---|---|---|
| R1 | 管理接口在上游不可达时 **5 秒内返回** | 后端 `AdminFetchTimeoutSeconds` + last-good 兜底 |
| R2 | `/sub` 上游不可达时 **10 秒内返回**，且带 stale 降级 | 后端 `PublicSubFetchTimeoutSeconds` + `X-Cache: stale` |
| R3 | 后台刷新失败按 **15→30→60→120 分钟** 退避 | `BackgroundRefreshService`（不动） |
| R4 | 数据单一来源：raw 快照 → merged/nodes/groups 派生 | `ClashSubService`（不动） |
| R5 | 列表接口响应需携带 `lastGoodUpdate`/`isStale`，供前端渲染 stale 警告 | **本次改造新增约束** |
| R6 | `/sub` 面向 Clash 客户端，`content-type` 不改、不走登录 | 后端 |
| R7 | 前端首屏不得被抓取阻塞（先渲染缓存/占位，数据异步到达） | Vue 页面组件 |
| R8 | 管理端鉴权 **fail-closed**：未配置用户名/密码拒绝登录；`/api/*` 全量受保护（白名单除外）；Cookie `SameSite=Lax` + 写操作自定义头防 CSRF；改密/改名后旧会话失效；登录限速（同来源失败 5 次锁 30 秒） | 后端认证 + 前端 api 模块 |

## 5. 通用约定

- **语言**：文档、接口字段命名、前端文案统一中文（接口 JSON 字段沿用现有 camelCase，如 `accessToken`）。
- **后端接口路径**：统一 `/api/*`。
- **DTO**：前后端交互用独立 DTO，不直接暴露存储模型（见卷 01 §0.3）。
- **验证**：每一步保留一份小验证清单；阶段 7 汇总全量回归。
- **分支策略（v2）**：开工即建 `refactor/vue3-spa` 分支并打基线 tag（延续 `fix/sub-fault-tolerance` 的做法），每个阶段独立 commit，任何阶段可整体回退。

## 6. 输出位置

- 原始数据存储不变：`Data/rules.json`、`Data/settings.json`。
- 前端源码建议新目录：`web/`（或 `ClientApp/`，最终以卷 05 为准）。
- Vue 构建产物最终落入后端 `wwwroot/`（见卷 04、07）。
